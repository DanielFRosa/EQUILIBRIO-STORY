# Equilíbrio Store

Sistema web de gestão comercial e catálogo digital desenvolvido para uma loja de vestuário.

O projeto tem como objetivo digitalizar processos comerciais, facilitar o controle de estoque, registrar vendas e disponibilizar uma vitrine digital de produtos.

## Sobre o projeto

A Equilíbrio Store é uma aplicação Full Stack que integra um ambiente administrativo para gerenciamento da loja e um catálogo público para apresentação dos produtos.

O sistema está sendo desenvolvido como um projeto prático de Engenharia de Software, com foco em arquitetura, modelagem de dados, regras de negócio e desenvolvimento web.

## Funcionalidades

### Área administrativa
- [ ] Autenticação de usuários
- [ ] Dashboard de vendas

- [ ] Controle de tamanhos e cores
- [ ] Controle de estoque
- [ ] Registro de vendas
- [ ] Gerenciamento de pagamentos
- [ ] Cadastro de clientes
- [ ] Relatórios comerciais

### Catálogo digital
- [ ] Página inicial da loja

## Arquitetura

A aplicação utiliza uma arquitetura organizada em camadas, separando as responsabilidades de apresentação, regras de negócio, acesso aos dados e persistência.

## Banco de dados

O banco de dados relacional é responsável por armazenar usuários, produtos, categorias, variações, clientes, vendas, pagamentos e movimentações de estoque.
